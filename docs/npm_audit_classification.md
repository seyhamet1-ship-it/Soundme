# NPM Audit Security Assessment & Classification

**Date:** 2026-10-18  
**Scope:** `frontend/` package dependencies  
**Tool:** `npm audit` (audited 325 packages)

---

## Summary

`npm audit` reports **13 vulnerabilities** across 5 dependency clusters:
- **Critical (2):** `tinypool` (Prototype pollution)
- **High (6):** `braces` (Stack exhaustion DoS via `chokidar` / `tailwindcss`)
- **Moderate (5):** `esbuild` (Dev server CORS request leak), `@vitest/mocker` (Path traversal mock redirect), `postcss-selector-parser` (CPU exhaustion)

All 13 vulnerabilities reside **exclusively in devDependencies** used for local testing, CSS pre-processing, and dev-server execution. **None** are included in the production runtime bundle generated by `npm run build`.

---

## Detailed Classification

| Vulnerability Package | Severity | Path / Chain | Environment | Production Impact | Remediating Action |
|---|---|---|---|---|---|
| `tinypool <= 2.1.1` | Critical | `vitest -> tinypool` | **Dev / Test only** | **None** (Test runner worker thread manager; not shipped to browser) | Requires Vitest 5.x upgrade (breaking change to vitest suite API). |
| `braces *` | High | `tailwindcss -> chokidar -> braces` | **Dev / Build only** | **None** (File watcher for Tailwind CSS hot reload; only runs during build/dev) | Requires Tailwind CSS 4.x upgrade (breaking CSS engine changes). |
| `esbuild <= 0.24.2` | Moderate | `vite -> esbuild` | **Dev server only** | **None** (Vite development local server; production uses pre-bundled static JS) | Requires Vite 8.x upgrade (major breaking bump). |
| `@vitest/mocker <= 4.1.10` | Moderate | `vitest -> @vitest/mocker` | **Dev / Test only** | **None** (Mocking utility in test suite; never bundled) | Requires Vitest 5.x upgrade. |
| `postcss-selector-parser < 7.1.6` | Moderate | `tailwindcss -> postcss-nested -> postcss-selector-parser` | **Build only** | **None** (CSS AST parser for nested selector expansion during compilation) | Requires Tailwind CSS 4.x upgrade. |

## Recommendation & Non-Breaking Resolution

Non-breaking patches were attempted via `npm audit fix` (reported "up to date, audited 325 packages, 0 non-breaking fixes available"). The upstream fixes require `vitest@5.0.5`, `tailwindcss@4.3.3`, and `vite@8.3.4`, which are major breaking upgrades. Because all vulnerabilities are dev-only and do not affect the compiled production artifacts, they are classified as **ACCEPTED_DEV_ONLY** for the v1.0.0 release.
